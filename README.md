# Cold Storage Warehouse Management System

A Java-based warehouse management application built using Object-Oriented Programming (OOP).

## Features
- Receive and dispatch goods
- Manage stock quantities and product details
- Support for perishable and fragile items
- Calculate storage charges and dispatch bills
- Search products and view inventory
- Generate low-stock and expiry reports
- Save warehouse data locally

## Technologies
- Java
- OOP: Inheritance, Interfaces, Encapsulation, and Method Overriding
- Java Serialization for local data persistence

## How to Run

1. Install the Java JDK.
2. Open the `src` folder in the terminal.
3. Compile the program:

   `javac *.java`

4. Run the program:

   `java Main`
